\section{Prestazioni e SEO}

Le performance del sito sono un aspetto chiave per ottenere una buona visibilità sui motori di ricerca e nei vari canali digitali. Per questo motivo sono state adottate le seguenti strategie:
\begin{itemize}
    \item Tutti i file Javascript e CSS sono stati minimizzati per ridurre i tempi di caricamento.
    \item Il codice PHP è stato scritto privilegiando l’early return, così da ottimizzare l’esecuzione.
    \item Per le immagini si è scelto il formato WebP, che consente di diminuire la dimensione dei file senza comprometterne la qualità.
    \item Sono state definite regole di caching più efficienti per i contenuti statici tramite il file di configurazione htaccess.
    \item Sono state seguite le raccomandazioni di Google Lighthouse, mantenendo comunque la separazione tra contenuto e presentazione (ad esempio evitando l’inlining delle regole CSS principali). Nei test effettuati, il sito ha raggiunto il punteggio massimo (100\%) in tutte le categorie, ad eccezione delle prestazioni dove si raggiunge comunque il 100\% nella maggior parte delle pagine e un minimo dell’85\% nelle situazioni meno favorevoli. Nella pagina Contatti, a causa dell’integrazione con Google Maps, il punteggio in Best Practices scende al 78\%.
\end{itemize}
